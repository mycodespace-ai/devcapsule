# Pile Of Ideas

One file per idea nobody has triaged yet. The rules are topic 12.13 of
[`WORKFLOW.md`](../../WORKFLOW.md); this page only shows the shape of a file.

Name the file `YYYY-MM-DD-<slug>.md`. It needs no more than this:

```markdown
# The idea in one line

From: who had it, and the date.

What the idea is, and why it could be worth doing.

## A part, when the idea has parts

What this part is.
```
